# 🎲 Random Number Generator

A simple beginner-friendly Python project that generates a random number within a user-defined range.

## ✨ Features
- Takes starting and ending numbers as input
- Generates a random number
- Simple and easy to use

## 🛠️ Technologies
- Python 3
- `random` module
